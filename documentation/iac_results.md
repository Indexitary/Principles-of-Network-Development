# Infrastructure as Code Results

This lab introduced Infrastructure as Code concepts.

A YAML infrastructure file was created to describe network devices,
switches and servers.

The YMAL configuration successfully represented:
- Routers
- Switches
- Servers
- Network roles
- IP addressing

The configuration was validated using Python and PyYAML.

## Comparison

Manual configuratio nrequires individual device files.

Infrastructure as Code defines the desired network state in a
structured YAML file.

IaC improves consistency, automation and scalability.

## Tools

The YAML configuration could conceptually be used by:
- Terraform for infrastructure provisioning
- Ansible for device configuration

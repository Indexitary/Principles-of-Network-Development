# REST API Automation Results

This lab demonstrated how Python communicates with the Flask
REST API created in Lab 6.

The Python automation script successfully:

- Retrieved network devices using GET requests.
- Processed JSON responses.
- Created new devices using POST.
- Updated devices using PUT.
- Deleted devices using DELETE.

The lab demonstrated how REST API automation reduces manual
network administration tasks.


In Lab 6, REST API requests were manually tested using Postman.
In Lab 8, Python automated these requests by communicating 
directly with the Flask API.

Python automation allows multiple operations to be completed
automatically, reducing repetitive administration tasks.
